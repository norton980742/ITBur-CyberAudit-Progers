## Описание проекта

Разработанный нами продукт (CLI приложение) полностью выполняет функционал, описанный в ТЗ. Конкретнее: анализирует опасные права директорий, делает сканирование сетей и сервисов, которые слушают эти сети, сопоставление версий установленного ПО с CVE, а так же, выдает полный список рекомендаций по устранению найденных уязвимостей.
