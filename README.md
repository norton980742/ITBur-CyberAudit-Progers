## Описание проекта

Разработанный нами продукт (CLI приложение) полностью выполняет функционал, описанный в ТЗ. Конкретнее: анализирует опасные права директорий, делает сканирование сетей и сервисов, которые слушают эти сети, сопоставление версий установленного ПО с CVE, а так же, выдает полный список рекомендаций по устранению найденных уязвимостей. Так же, наша программа имеет два варианта запуска: с графическим и консольным интерфейсом.

## Системные требования

Операционная система: GNU/Linux (Arch, CachyOS, Kali) <img src="https://cdn-icons-png.flaticon.com/128/6124/6124995.png" height=20 align="center">  
Необходимая версия Python: Python 3.13.9 <img src="https://cdn-icons-png.flaticon.com/128/5968/5968350.png" height=20 align="center">  
Список зависимостей: Стандартные зависимости Python  
Команда для запуска приложения: python main.py

## Инструкция по установке и запуску:

```bash
git clone https://github.com/norton980742/ITBur-CyberAudit-Progers  
cd ITBur-CyberAudit-Progers  
```
Запустить консольный вариант:

```bash
python main.py
```

Запустить графический вариант:

```bash
python main_ci.py
```
